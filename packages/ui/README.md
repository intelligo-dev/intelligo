# @intelligo-dev/ui

The legacy design system. Not part of the page contract.

Part of [Intelligo](https://github.com/intelligo-mn/framework), an application
framework and operational platform for vertical AI SaaS products. This package
is published from that repository and is not meant to be used on its own.

## Install

```bash
pnpm add @intelligo-dev/ui
```

Pages ship through the [registry](https://intelligo.dev/r) as consumer-owned
source, not from this package (ADR-0002, ADR-0010). What remains here is used
by the admin console.

New work belongs in `packages/registry/base/`.
